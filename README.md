# Jadlis — два стиля ответа для Claude Code

Два стиля ответа (output style — инструкция, которая задаёт форму ответа Claude Code). Оба написаны для читателя с СДВГ: сначала результат, коротко, простыми словами.

```
git clone https://github.com/beCyborg/jadlis-output-styles.git
sh jadlis-output-styles/install.sh --plan
sh jadlis-output-styles/install.sh
```

Затем в Claude Code набери `/output-style` и выбери стиль.

## Какой стиль для чего

| Стиль | Файл | Что делает |
|---|---|---|
| **Jadlis** | `jadlis.md` | Ответ начинается с результата. Потом — что это значит для тебя. Причины и детали — в конце, и только те, что меняют твой следующий шаг. Агент спорит с ошибочной посылкой, а не поддакивает. Действие для тебя — последней строкой «**От тебя:**». |
| **Jadlis Voice** | `jadlis-voice.md` | Тот же ответ на экране, а в конце — блок «🔊 Голосом»: пересказ ответа для слуха. Без разметки, без путей и команд, с тегами эмоций для голоса. |

Jadlis подходит всем, кто читает ответы глазами. Jadlis Voice нужен, только если ты слушаешь ответы.

**Для Jadlis Voice нужен голосовой движок с тегами.** Блок рассчитан на ElevenLabs Eleven v4: движок исполняет теги в квадратных скобках (`[warm]`, `[short pause]`) как интонацию. Другой движок прочитает теги вслух. Озвучку ставит плагин `jadlis-voice` из маркетплейса Jadlis. Без него блок можно выделить и отдать любому чтецу, но теги прозвучат как слова.

Язык ответа задаёт ключ `language` в `settings.json`, а не стиль. Блок «Голосом» написан для русской речи.

## Установка

`install.sh` копирует оба файла в `~/.claude/output-styles/`. Если задана переменная `CLAUDE_CONFIG_DIR`, скрипт пишет в `$CLAUDE_CONFIG_DIR/output-styles/`.

- `--plan` показывает, что изменится, и ничего не пишет. Для изменённого файла скрипт печатает дифф.
- Если файл уже есть и отличается, скрипт сначала копирует его в `<файл>.bak-<дата>`.
- Повторный запуск печатает `UNCHANGED` и ничего не пишет.

Стиль по умолчанию задаёт ключ `outputStyle` в `~/.claude/settings.json`: `"outputStyle": "Jadlis"`. Если файла стиля нет, Claude Code молча включает стиль Default.

Обновить: `git -C jadlis-output-styles pull`, затем снова `install.sh`.

## Что рядом

- [jadlis-claude-md](https://github.com/beCyborg/jadlis-claude-md) — глобальный `CLAUDE.md`: как агент понимает задачу, проверяет результат и пишет для людей.
- [jadlis-claudecode](https://github.com/beCyborg/jadlis-claudecode) — плагин, который собирает Claude Code и терминал. Он включает стиль Jadlis в настройках и может поставить этот репо одним шагом.
